# my-sysadmin-scripts

Репозиторий для домашнего задания курса системного администрирования.

## Скрипт: Мониторинг ресурсов (Вариант Б)

Скрипт `script.sh` выполняет автоматический сбор информации о ресурсах системы с заданным интервалом.

### Что делает скрипт
- Каждые N секунд (захардкожено как константа `INTERVAL=5`) снимает показатели:
  - Использование оперативной памяти (`free -h`)
  - Использование дискового пространства (`df -h`)
  - Время работы системы и нагрузку (`uptime`)
- Записывает данные в файл `monitor.log` с временными метками
- Обрабатывает ошибки (проверка прав на запись)
- Корректно завершается по Ctrl+C с сообщением

### Запуск
```bash
chmod +x script.sh
./script.sh
